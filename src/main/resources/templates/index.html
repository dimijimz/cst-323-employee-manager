Employee Manager

A deliberately small Spring Boot CRUD application built for CST-323 Cloud Computing. The feature set is minimal on purpose: the point of the project is to redeploy the same codebase onto multiple cloud platforms, starting with Microsoft Azure, and to compare what each platform asks of the application.

What it does

The application manages employees and the departments they belong to, a one-to-many relationship persisted in MySQL through Spring Data JPA. All four CRUD operations are reachable from the UI.

  • Create - add an employee from the shared form
  • Read - browse the roster or open one employee
  • Update - edit an existing employee
  • Delete - remove an employee from the roster

Built for portability

Nothing environment-specific is compiled into the jar. Each deployment target supplies its own values and the application adapts.

  • Java 17 · Spring Boot 3 - single executable jar
  • Externalized config - database host, name and credentials all read from environment variables
  • Flyway migrations - the schema and seed data rebuild themselves on a brand new database
  • SLF4J logging - every CRUD operation logged at INFO to stdout, where cloud log collectors can read it
  • Health endpoints - /health for liveness and /actuator/health for readiness
